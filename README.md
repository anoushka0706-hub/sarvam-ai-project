# sarvam-ai-project

Sarvam AI starter project for building voice-first applications. It includes a Python chat example using Sarvam’s sarvam-105b-conversations model and a voice-cloning script that turns a clean speech sample into narrated audio. The scripts read SARVAM_API_KEY from the environment; keep your key in .env and out of version control. The voice-cloning example requires a supported audio file and a speaker’s permission to use their voice.
